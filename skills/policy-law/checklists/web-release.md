## 使い方

- `../jurisdictions/` の該当項目と照合し、根拠を確認してから判定する。
- 未充足項目は根拠 URL とあわせて一覧化し、専門家レビューに回す。

## プライバシー・個人情報

- [ ] プライバシーポリシーを公開し、取得情報と利用目的を明記している。
- [ ] アクセス解析等の外部送信の有無と送信先を開示している。
- [ ] Cookie 等の利用方針を明記している。
- [ ] 漏えい等の発生時の連絡・報告フローを定めている。
- [ ] 開示・訂正・削除等の請求窓口を明記している。

## コンテンツ・権利

- [ ] コード・画像・フォントのライセンス表示が正確である。
- [ ] 引用は出典明記等の要件を満たしている。
- [ ] 利用規約の有無と適用範囲が適切である。
- [ ] 他者の商標・肖像を許諾なく使用していない。

## 商取引（販売・課金がある場合）

- [ ] 特定商取引法に基づく表記がある（氏名・所在地・連絡先等）。
- [ ] 価格・送料・支払方法・引渡時期を表示している。
- [ ] 返品特約（返品条件）を表示している。
- [ ] 申込み最終確認画面の表示が適切である。
